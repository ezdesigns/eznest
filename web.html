What OUTPUT sees

Connecting to OUTPUT is optional. Nesting, saving, and stock work without it. The connection is separate from sharing activity.

Sent when you connect: this computer's name and this installation id, once, in the pairing request. Later check-ins send the app version. The shop credential authenticates those HTTPS requests. OUTPUT also sees this computer's IP address on those requests.

Sent only after Enable sharing, and only for new activity: a stable installation id, opaque layout and request ids, the exact event time, the app version, the event type, a standard material category, and the measurement ranges below. Measured stock readings already on this host can be included. Earlier activity is excluded. A failed delivery is retried with the same event id. The shop stock ledger stays here.

Never sent: artwork, files or filenames, customer names or contacts, job codes, roll ids, custom material names, exact dimensions, quantities, stock contents, or search time. These are local observations; “printed” means an explicit operator confirmation, not independent proof of physical printing.

Sharing capacity and availability with the OUTPUT network is a separate opt-in. It stays off until you turn it on. It is not this connection, and it is not Enable sharing.

Ez Nest does not send a price.

Material categories: moto_regular, moto_holographic, moto_chrome, custom, unknown or null. Stock-only observations have no layout ID.

Leave blank for https://output.jeezlabs.io. Change it only on this computer. Another address has to match EZ_NEST_OUTPUT_URL, set when Ez Nest starts. Activity sharing stays off until you agree here. Connecting to OUTPUT is optional.
