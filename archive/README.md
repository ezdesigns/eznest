# Archive

These files are not part of the shop page. They are kept so the older notes and the Illustrator experiment are still in the repository.

| Path | What it was |
| --- | --- |
| `HANDOFF.md` | Notes from the earlier handoff. The shop page does not read this file. |
| `HANDOFF-MANIFEST.json` | File list that belonged to that handoff. |
| `classic.html` | The earlier one-page workspace. The shop page is `/web`. The full workspace remains `/`. |
| `Apply layout.jsx` | Illustrator script that applied a nest to a new document. |
| `Capture selection.jsx` | Illustrator script that captured a selection. |
| `jsx/host.jsx` | Illustrator host bridge used by those scripts. `tests/test_boundaries.cjs` still checks its boundary rules. |

The Windows package does not include this folder. Nothing here runs when a shop installs Ez Nest.
