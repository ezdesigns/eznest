eznest 0.11.0-beta.1 | Windows x64 | Production-file beta

START
Extract the complete ZIP into a writable folder and open eznest.exe.
Keep _internal beside it. No separate Python installation or account is needed.
The local browser opens http://127.0.0.1:8765/. Stop an older version first.

NEST
1. Drop PDF, PDF-compatible AI, or SVG files.
2. PDF/AI requires existing closed spot-color cut contours, normally CutContour.
   Enter existing bleed to retain, then review every detected piece and its size.
   Zero bleed clips at the cut. eznest does not generate missing bleed.
3. Choose usable roll width and complete-set quantities. Length is automatic.
4. Optional: enter customer/order/kit in job options. Set per-sheet length and
   material pricing in Settings. No printer/cutter model is required.
5. Nest, review, and export. Multiple sheets become numbered print files.
   The separate map/checklist identifies pieces without printing sorting labels.

PDF/AI jobs export original-object PDF with a real named cut spot and separate
layer. SVG jobs export SVG. Keep these formats in separate batches. Use Preserve
source colors and let the RIP handle printer color management and registration.
The ONYX profile may need its bleed requirement confirmed before it can be met.

LIMITS
One material, up to 100 pieces. PDF: 20 MB, 25 pages. AI must have Create PDF
Compatible File enabled. Hidden/conditional PDF layers, annotations, ambiguous
contours and some other structures are rejected. DeviceN cut colors are unsupported.
No EPS, automatic bleed, color conversion, inventory or printer/cutter dispatch.
This beta is not yet validated through physical ONYX/GoProduce equipment.
Source clipping is not confidential-content redaction. Use print-only source art.

OPTIONAL TOOLS
Sticker fill adds complete sets in spare space. Material costs exclude ink,
laminate, labor, overhead and profit. Layout details includes a comparison worksheet.
Exports holds frozen batches and lets you add jobs back to the queue. Exported does
not mean printed. Failed browser fetches leave jobs active for retry.

YOUR DATA
Queue/settings live in the same browser/address. Imported documents and frozen
batches live in data/ beside the executable. Keep both when upgrading. Back up
exports. Originals are never edited or deleted. Watched folders still use SVG.

STOP
Help > Quit eznest stops the local service. Closing the browser alone does not.
Keep all licenses/ notices and covered source when redistributing the package.
