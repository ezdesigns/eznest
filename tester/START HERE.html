Start here

  1. Extract the whole ZIP to a new folder on a separate Windows 10/11 computer (64-bit x64). Keep all the files together.
  2. Double-click START EZ NEST.cmd. Your browser opens the app. No Python, account, or administrator setup is needed.
  3. Drop Examples/sample-artwork.svg into the app. Leave Sets at 1. Review the four pieces, then choose Review and send → Confirm send.
  4. Open OPEN Test Output.cmd. Check the saved pack. Sending to this folder does not print anything.

If Windows blocks this unsigned trial, send the warning to the person who gave you the kit. Do not turn off security protections. If another EZ Nest is running, leave it alone and use a separate test computer.

Then try your work

Use a copy of a prepared PDF, PDF-compatible AI, or SVG. Choose your material and quantity, inspect every piece and cut, then send to TEST Output. Match your actual printable width; the supplied material defaults are examples.

Look for
Correct quantities · unchanged size · complete artwork · correct cut lines · useful material savings.

Try changing
Material spacing and quantity. Hover or tap i for help. Save material, close and reopen the browser, and check it remembers.

Finish colors and bleed before importing. PDF/AI files must be under 32 MB; SVG under 8 MB. Dashed, clipped, or unrecognized cuts may need correction in the design file.

Using Illustrator

Save the design and select complete parts with their cuts. Run File → Scripts → Other Script → Illustrator/Prepare and Nest.jsx. Keep the script files together. Choose your approved PDF preset, printable width and existing bleed on the first run. EZ Nest Settings.jsx changes these later.

Use layers thru-cut and kiss cut, or the spot names CutContour_Thru-cut and CutContour_Kiss-cut. The script makes a separate production copy. Regular material preparation is supported; specialty color rules are not automated.

Before any physical print test

Have your shop operator inspect the saved output in ONYX using the correct media settings. Print and cut a small approved sample first. Measure a known part, compare colors and bleed, and check cutter alignment. Keep this trial pointed at TEST Output. A successful nest is not proof of production quality.

Stop, update, or get help

Code changes do not update this copy automatically. When your organizer sends a newer ZIP, use CODEX UPDATE PROMPT.txt for help. How updates work.

The app will not open

Extract the whole ZIP first. Keep the app folder intact. Use a 64-bit x64 Windows PC. If you closed the browser but left this trial running, reopen http://127.0.0.1:8765/web. If startup says another build is running, do not close a production app to make room. Record the message in the feedback form.

Stop or update this trial

Finish nesting, then use STOP Shop Test.cmd. Closing the browser alone leaves the app running. Before updating, copy %LOCALAPPDATA%\eznest-shop-trial to a dated backup while the app is stopped. Extract each new kit to a new folder; keep the old kit as a fallback. Start the new kit. To go back, stop it and start the old kit.

What is saved and what is still missing?

Jobs and test output stay on this PC under %LOCALAPPDATA%\eznest-shop-trial. Material presets stay in this browser. Keep using the same browser to keep those presets. No customer artwork is included in this kit.

Automatic recoloring, editable nested layouts returned to Illustrator, remaining-order counts and automatic stock deduction are not included. Actual print/cut acceptance and clean-PC compatibility need tester confirmation. Automatic app updates are off for this trial.
