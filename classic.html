Preparing SVG artwork

Each top-level shape or group is one part. A group needs one clipping outline, a CutContour path, or a closed path named EZN_BOUNDARY. Outline text, embed images, and expand live effects. Dimensions follow the SVG’s physical size; pixels use 96 pixels per inch. Downloaded SVGs preserve supported artwork and clipping, but RIP spot colors and bleed need separate checks. One sheet per job, up to 100 copies.

Optional Illustrator connection

Run Capture selection.jsx through Illustrator → File → Scripts → Other Script, then choose “Load Illustrator capture” here. After reviewing a layout, prepare the output and run Apply layout.jsx. Select closed paths or complete groups. Groups need one outer clipping path, one CutContour path, or an explicit closed path named EZN_BOUNDARY. All artwork inside the group is copied together. Bleed is not generated; nesting uses the identified boundary. Compound boundaries with holes and live effects still need further support.
