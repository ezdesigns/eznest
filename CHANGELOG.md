# Changelog

The in-app What's new panel reads this file. Newer versions go at the top.

## 0.12.0-beta.1 — Mixed-cut beta

### For testers
- Windows portable ZIP is built by the Windows portable GitHub Actions workflow and attached to that run. It is not a published release.
- What's new lists the changes in this build.
- Update now, or install on the next restart. Ez Nest downloads the portable ZIP, checks its SHA-256 checksum, keeps jobs and settings, and restores the previous build if the new one does not start.
- Report a problem opens a GitHub issue with the version filled in.

### Nesting
- One piece owns its print artwork, outer boundary, and every interior cut.
- Thru-cut, kiss-cut, and generic cuts stay together through rotation, copies, and sheets.
- Shareable cut mappings, and an explicit choice when a generic cut has no type.
- Recognized old registration marks are removed. The RIP adds new marks.
- PDF and PDF-compatible AI export original drawing objects. SVG stays a separate batch.

Active PDF/AI jobs imported before 0.12 need to be added again and reviewed. Frozen packages already saved are left as they are.
