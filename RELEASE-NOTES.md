# eznest 0.10.0-beta.1 — Windows SVG nesting beta

Portable Windows x64 download. Extract the complete Windows ZIP and open `eznest.exe`; no separate Python installation is required. The app runs locally in your browser.

## Included

- Drop SVG artwork, choose roll width and complete-set quantities, nest, and export.
- Automatic roll length, configurable physical units and reusable material presets.
- Multiple jobs in one layout, optional sticker fill and separate sorting maps/checklists.
- Export history and local destination folders.

## Beta limits

Unsigned Windows build; one material and up to 100 pieces per batch. SVG is the supported import/export format. Native AI/PDF artwork, production PDF/EPS output, CMYK conversion, bleed generation and named cut-spot output are not yet implemented. ONYX exports remain working SVG files. No direct printer or cutter output. Layout search is heuristic.

41 Python tests and the JavaScript queue/profile/boundary checks passed locally. The portable executable was tested through file import, native nesting, download and folder export, saved history, shutdown and reopening. A separate clean Windows installation and actual ONYX/GoProduce production validation remain outstanding.

Download the attached **windows-x64.zip** to run the app. GitHub's automatically generated source-code archives are for development. SHA-256 values are in the attached checksum file.
