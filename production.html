      Settings

      Workspace

      Units apply throughout eznest. Changing units converts measurements without resizing artwork. Prepared jobs leave the active queue after a successful save; find them under Exports.

      Material preset

      Fixed by your material. Length is calculated from the jobs you select.

      Gap is measured from imported contours. Bleed is not added. Confirm the starter shop preset against your printer.

      Optional default length limit

      Usually left blank. This limits total material across all sheets. Set per-sheet handling limits under Sheets and material cost.

      Sheets and material cost

      Optional. Splits the batch into numbered sheets without cutting pieces. Total roll length remains a separate limit. Include registration and handling space in your margins.

      Material only. Shared waste is allocated by occupied piece area. Ink, laminate, labor, overhead and profit are excluded.

      Automatic nesting

      While eznest is open. Stops after five extra searches or three without improvement. Saving freezes the batch.

      File requirements

      PDF and PDF-compatible AI need closed, stroked named spot-color contours, usually CutContour. Review detected pieces before nesting. Hidden/conditional PDF layers, annotations and ambiguous contours are rejected. SVG pieces still need complete groups and clear boundaries. Keep PDF and SVG jobs in separate batches. Color conversion, bleed generation and printer control stay outside eznest.

      Folders

      Folder watching currently adds SVG files. Add PDF/AI with Add files or drag and drop so you can choose and review their cut contours and bleed. New watched jobs start unselected.

      Each saved nest gets its own folder with artwork, a piece map and a checklist. Choose a location outside the source folder.

      Job options

      Review detected pieces

      This is a visual/operator check. eznest does not verify ink coverage or create bleed. Re-add the file to change its bleed allowance or cut recognition. Interior cuts belong to the surrounding piece; separate pieces inside other pieces are not inferred.

      Customer, order and category

      Exported files

      Saved batches. Exporting does not send files to a printer. Source files stay untouched.

      Shop / RIP profile

      Each shop can share its own file requirements. RIP media presets and printed job logs stay in the software that runs the printer.

      Cutting and finishing
      Cut type mappings

      Starter names recognize common thru-cut, kiss-cut and registration layers or spots. Confirm them against your files. Use one exact, case-sensitive name per line, or start a line with prefix: to match a prefix. Conflicting rules stop import.

      Unmapped cut-name checks

      Thru-cut and kiss-cut keep separate output layers and spot colors. Tool notes are references for the operator; eznest does not send tool-slot commands. Recognized old registration marks are removed so the RIP or finishing software can generate new sheet marks.

      Workflow ownership

      PDF/AI jobs export PDF with preserved artwork and separate named spots and layers for each cut type. SVG jobs export SVG. Choose Preserve source colors for RIP color management. EPS conversion and automatic bleed are not provided. Readiness is checked against the actual batch.

      Start with a nest

      1. Add your artwork. Drop files anywhere. Each file is a job; a set includes every piece in that file.
      2. Check the roll width and quantities. Length is automatic. Set units, spacing and rotation in Settings.
      3. Nest, review, export. Click a job below the preview to find its pieces. Export saves the artwork plus a separate sorting map and checklist.

      Use print-only artwork at actual size. PDF/AI needs mapped cut strokes with a closed outer boundary for each piece; review the detected pieces and existing bleed. SVG needs grouped pieces with a clipping outline, CutContour or EZN_BOUNDARY. Originals are never changed.
