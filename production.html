    Settings

    Workspace

    Units apply throughout eznest. Changing units converts measurements without resizing artwork. Prepared jobs leave the active queue after a successful save; find them under Exports.

    Material preset

    Fixed by your material. Length is calculated from the jobs you select.

    Gap is measured from imported contours. Bleed is not added. Confirm the starter shop preset against your printer.

    Optional default length limit

    Usually left blank for roll printing. Set this only when a cutter or handling rule limits each batch. This is a maximum, not a fixed print length.

    Automatic nesting

    While eznest is open. Stops after five extra searches or three without improvement. Saving freezes the batch.

    File requirements

    SVG only in this build. Each file is one job; each closed shape or complete group is a piece. Groups need a clipping outline, CutContour path or EZN_BOUNDARY. Outline text and embed images. AI/PDF artwork import, automatic bleed and production spot-color output are still pending.

    Folders

    Files are added to the queue as they arrive. New jobs start unselected.

    Each saved nest gets its own folder with artwork, a piece map and a checklist. Choose a location outside the source folder.

    Job options

    Exported files

    Saved SVG batches. Exporting does not send files to a printer. Source files stay untouched.

    Shop / RIP profile

    Each shop can share its own file requirements. RIP media presets and printed job logs stay in the software that runs the printer.

    Cutting and finishing
    Workflow ownership

    This build imports and exports SVG. PDF/EPS export, CMYK conversion, bleed and named cut-spot output still need implementation. Jobs stay active when a saved working package does not meet this profile.

    Start with a nest

    1. Add your SVG artwork. Drop files anywhere. Each file is a job; a set includes every piece in that file.
    2. Check the roll width and quantities. Length is automatic. Set units, spacing and rotation in Settings.
    3. Nest, review, export. Click a job below the preview to find its pieces. Export SVG saves the artwork plus a separate sorting map and checklist.

    Use print-only artwork at actual size. Outline text and embed images. Keep each piece grouped with its clipping outline, CutContour or EZN_BOUNDARY. Originals are never changed.

    SVG nesting beta · up to 100 pieces, one material per batch. PDF/AI artwork, CMYK conversion, automatic bleed and production cut-spot export are not supported yet. ONYX jobs export as working SVG and stay in the queue.
